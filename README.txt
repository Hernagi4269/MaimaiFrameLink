Maimai Frame Link v0.8.0

目的
- サブiPhoneでmaimaiを1080p/60fps撮影
- メインiPhoneから直前動画をネットワーク越しに確認
- 1F/10F送り、前後動画、保存、削除、切り抜き
- Wi-Fiルーターやテザリングがない場所ではApple peer-to-peer Wi-Fiを使用

v0.8.0 安定化
- P2Pの「接続済み」はローカルプロキシ起動だけではなく、撮影側 /api/health の実通信成功後に表示
- 撮影側Bonjour名を端末固有ID化し、一度接続した撮影側を確認側が優先して再接続
- 録画中ファイルを InProgress に隔離し、AVFoundationの書き込み完了後だけ Recordings に移動して公開
- 録画ファイル名をミリ秒+UUIDで一意化
- 5秒movie fragmentを有効化し、異常終了時の動画損失リスクを軽減
- System Pressureを監視し、critical/shutdownでは動画保護を優先して録画停止
- Capture Session中断/Runtime Error後の自動再始動を追加
- 録画中の役割変更を禁止
- 撮影側は低電力モードでも自動スリープを無効化
- 録画中の省電力表示ではプレビュー描画を停止し、黒画面+最小UIに変更（録画品質には影響なし）
- H.264 1080p60は16Mbpsを基準にして、画質を維持しつつストレージ/転送量を少し削減
- Sideload版のembedded.mobileprovisionから期限を取得できた場合、残り2日以下で画面上部に警告
- 確認側横画面UIを動画優先レイアウトへ変更。シーク/フレーム操作を下部へ集約し、保存/削除/切り抜きは「…」へ収納

外出前に交通費をかけずP2Pだけをテストする方法
1. 2台ともMaimai Frame Linkを最新版にする
2. テザリングをOFF
3. 2台ともモバイルデータ通信をOFF（機内モードでも可。ただしWi-FiとBluetoothは個別にONへ戻す）
4. 自宅Wi-Fiから2台を切断する。Wi-Fi機能自体はONのままにする
5. 撮影側を起動し、確認側を起動
6. 確認側が「接続済み（P2P実通信確認済み）」になることを確認
7. 確認側から録画開始→30秒程度待つ→確認側をロック→解除→録画中状態が復元されることを確認
8. 確認側から録画停止→最新動画が自動表示→音声/1F送りを確認
9. 10〜20分連続録画して発熱・バッテリー・保存を確認

重要
- 「接続済み（P2P実通信確認済み）」が出なければ、本番のゲーセンへ行く前にその状態を報告してください。
- 撮影側アプリをバックグラウンド/ロックするとiOSのカメラ制約で撮影継続できません。撮影側は前面・画面ONを維持します。
- 確認側は録画開始後にロックして構いません。復帰時に再探索・録画状態復元を行います。
- 無料署名は期限があります。アプリ内警告が出たら外出前にSideloadlyで再署名してください。
